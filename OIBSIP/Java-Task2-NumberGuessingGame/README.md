Project Overview

The Number Guessing Game is a Java application in which the computer generates a random number and the player tries to guess it within a limited number of attempts.

Technologies Used
Java
Java Swing
Eclipse IDE
Java Random class
Features
Graphical user interface
Easy, Medium and Hard difficulty levels
Random number generation
Too High and Too Low hints
Attempt counter
Score tracking across rounds
Win and lose messages
Play Again option
Input validation
How to Run
Install a compatible Java JDK.
Open Eclipse IDE.
Create or open a Java project.
Copy NumberGuessingGame.java into the project's source folder.
Run NumberGuessingGame.java as a Java Application.
