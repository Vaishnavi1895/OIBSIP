🎮 Task 1: Number Guessing Game
Project Overview

The Number Guessing Game is a Java Swing-based application in which players try to guess a randomly generated number within a limited number of attempts.

Features
Interactive graphical user interface.
Three difficulty levels: Easy, Medium, and Hard.
Random number generation.
Higher and lower hints.
Attempt counter and score tracking.
Win and lose messages.
Play Again option.
Input validation.
Technologies Used
Java
Java Swing
Eclipse IDE
How to Run
Install the Java Development Kit (JDK).
Open Eclipse IDE.
Create or import the Java project.
Place NumberGuessingGame.java in the source folder.
Right-click the main class and select Run As → Java Application.
Learning Outcomes
Practiced Java programming fundamentals.
Learned to use conditional statements and loops.
Implemented random number generation.
Understood event-driven programming using Java Swing.
Improved input validation and problem-solving skills.
🏦 Task 2: ATM Banking System
Project Overview

The ATM Banking System is a Java-based desktop application that simulates basic ATM operations. It provides a graphical user interface using Java Swing and demonstrates Object-Oriented Programming concepts.

Features
User authentication using User ID and PIN.
Access denial after three incorrect login attempts.
Withdraw money after checking the available balance.
Deposit money and update the account balance.
Transfer funds between demo bank accounts.
Display the current account balance.
View transaction history during the current session.
Logout and exit options.
Validation of transaction amounts and available balances.
Technologies Used
Java
Java Swing
Eclipse IDE
ArrayList
Object-Oriented Programming (OOP)

🚆 Task 3: Online Train Reservation System
Project Overview

The Online Train Reservation System is a GUI-based Java application designed to simulate train ticket booking and cancellation. It uses Java Swing for the interface, JDBC for database connectivity, and SQLite for data storage.

Features
Login using a username and password.
Access denied for invalid credentials.
Book tickets by entering passenger and journey details.
Automatically populate the train name using the train number.
Generate a unique PNR for each reservation.
Display booking confirmation with reservation details.
Fetch booking details using a PNR number.
Cancel bookings after user confirmation.
Validate required fields, journey dates, and numeric train numbers.
Use PreparedStatement for parameterized SQL queries.
Technologies Used
Java
Java Swing
JDBC
SQLite
Eclipse IDE
SQL
Demo Login Credentials
Username: admin
Password: admin123

Note: These credentials apply to the demonstration implementation. Change them before sharing or deploying the application.

How to Run
Install the JDK and open Eclipse IDE.
Import the Train Reservation System project.
Add the SQLite JDBC driver to the build path, or configure the dependency in Maven.
Ensure the database connection is configured correctly.
Run the application's main class as a Java Application.
Log in using the configured demo credentials.
Learning Outcomes
Learned database connectivity using JDBC.
Practiced SQL table creation and database operations.
Implemented create, read, and delete operations for reservations.
Used PreparedStatement to help prevent SQL injection.
Implemented PNR generation and booking retrieval.
Developed GUI forms with input validation.
Integrated Java Swing with an SQLite database.
Limitations

This project is an educational simulation. It does not connect to a real railway reservation network or check live train schedules or seat availability.
